 🏸 Sports Coaching Cart UI

A modern cart and booking interface built using **HTML and CSS** as part of my web development learning journey.

This project simulates a sports coaching booking system where users can view coaching session packages, manage their cart, and review their order summary before checkout.

 ✨ Features

* 🧑‍🏫 Coach booking cards
* 🏸 Sports category navigation
* 📅 Session schedule display
* 💰 Order summary section
* 💳 Pay Now button UI
* 🎨 Clean and structured layout
* 📱 Responsive-ready design

 🛠️ Tech Stack

* HTML5
* CSS3

 🎯 What I Learned

* Flexbox layout design
* Navigation bar creation
* Building card-based interfaces
* Structuring a shopping cart page
* Organizing webpage sections effectively

 🚀 Future Improvements

* Add JavaScript functionality
* Dynamic price calculations
* Remove/edit cart items
* Responsive mobile design
* Payment integration

 📌 Note

This project was built during my early web development journey to strengthen my frontend development skills and understand how real-world booking/cart interfaces are designed.
